# Assets and third-party licenses

The track, scenery, podium, textures, interface drawings, synthesized scores and race effects are generated by the game.

The local music library includes 56 Kevin MacLeod recordings under Creative Commons Attribution 4.0. Each recording was normalized and encoded to Opus. The catalog records the original download, ISRC, source page, license and file hashes. Open **Show settings → Music library and credits** to audition the recordings or download the attribution text. [Full credits](../public/music/credits.txt) · [License](https://creativecommons.org/licenses/by/4.0/)

For a YouTube broadcast, include the music attribution in the video description. YouTube can interrupt a licensed live stream when the rights holder has not allowlisted the channel. The composer accepts game-whitelisting requests. [Composer’s usage guide](https://incompetech.com/music/royalty-free/faq.html) · [YouTube live copyright guidance](https://support.google.com/youtube/answer/3367684?hl=en)
